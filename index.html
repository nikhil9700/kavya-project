About

Finance systems knowledge, shaped for real day-to-day use

I work with Oracle Fusion Financials and EPM Cloud end to end — from core finance setup and period close to planning, consolidation, and reporting. I focus on clear process design, clean configurations, and practical solutions that finance teams can use every day. My goal is to turn complex Oracle workflows into simple, reliable outcomes for GL, P2P, O2C, and EPM.

This portfolio is built as a set of deep knowledge case studies. Each project shows how I think through objectives, scope, phased approach, design decisions, controls, Oracle modules, deliverables, and outcomes — the same structure used in real implementation workshops and interview deep-dives.

Every project here is a knowledge case study. Not employment history, not company names, and not certification claims.
